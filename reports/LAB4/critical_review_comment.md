# Критический комментарий к рецензии БЯМ

**Лабораторная работа:** №4 (Пайплайн модели-валидатора: полный датасет и чанки)
**Обучающийся:** Скоробогатов И. В.
**Вариант:** №45 (Spambase)

| Пункт рецензии БЯМ | Позиция | Обоснование позиции |
| :--- | :--- | :--- |
| **1. Полнота комплекта артефактов** | Согласен | Все 4 обязательных файла сформированы, залогированы в MLflow и сохранены в `reports/LAB4/`. |
| **2. Точность совпадения статистик (0.000000)** | Согласен | Алгоритм раздельного накопления сумм и квадратов на чанках математически эквивалентен вычислению по полной матрице в памяти. |
| **3. Полнота отсева OOD (99.24%)** | Согласен | Комбинация диапазонного фильтра и стандартизированного расстояния эффективно блокирует искусственные дефекты и шум. |
| **4. Контроль ложных отказов (FPR <= 0.05)** | Согласен | Калибровка порога квантиля до 0.96 позволила снизить ложные срабатывания на валидации до 4.2%. |
| **5. Рекомендация: потоковый алгоритм квантилей (t-digest)** | Согласен | Для статичного файла двухпроходный стриминг оптимален, однако для онлайн-сервиса в ЛР 6–7 переход на t-digest исключит буферизацию. |
